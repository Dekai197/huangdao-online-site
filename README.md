# 荒岛突围 · 联机版

俯视角大逃杀小游戏 + 一个联机中转服务器。部署到网上以后，**任何人打开你的网址就能联机**，不需要 claude.ai 账号。

```
huangdao-online/
├── server.js          联机中转服务器（同时提供游戏页面）
├── package.json       依赖：只有 ws 8.22.0
├── package-lock.json
└── public/index.html  游戏本体（单人模式 + 联机模式）
```

服务器只负责把每个玩家的位置、开火、命中等状态转发给同房间的其他人，不跑游戏逻辑。

---

## 一、先在自己电脑上试（5 分钟）

1. 安装 Node.js 18 或更新版本：https://nodejs.org
2. 在这个文件夹里打开终端，运行：
   ```
   npm install
   npm start
   ```
3. 浏览器打开 `http://localhost:3000`
4. **和同一个 Wi-Fi 下的朋友一起玩**：查到你电脑的局域网 IP（比如 `192.168.1.23`），让朋友在手机上打开 `http://192.168.1.23:3000`。电脑防火墙可能需要放行 3000 端口。

## 二、部署到公网，让任何人都能打开

任何能运行 **Node.js 18+**、并且**支持 WebSocket** 的托管平台都可以。下面以 Render 为例。

> ⚠️ 以下步骤和免费额度规则是按我所知写的，**我没有在 Render 上实际部署验证过**，界面和规则可能已经变化，请以 Render 官网为准。据我所知，免费实例一段时间没人访问会休眠，第一次打开要等几十秒唤醒。

1. 注册 GitHub，新建一个仓库，把这个文件夹里的文件上传进去（**不要上传 `node_modules` 文件夹**）。
   网页上传：仓库页面 → Add file → Upload files → 把文件拖进去 → Commit。
2. 注册 Render（https://render.com），用 GitHub 登录。
3. New → Web Service → 选择刚才的仓库，然后填：
   - Runtime：Node
   - Build Command：`npm install`
   - Start Command：`npm start`
   - Instance Type：Free（或付费，付费不会休眠）
4. 创建后等部署完成，会得到一个网址，例如 `https://xxxx.onrender.com`。把它发给朋友就行。
5. 检查：打开 `https://xxxx.onrender.com/healthz` 应该显示 `ok`。

**其他平台**：Railway、Fly.io、自己的云服务器都可以。服务器读取环境变量 `PORT`（默认 3000）；如果你在 Nginx 后面跑，记得开启 WebSocket 转发（`/ws` 路径需要 `Upgrade` 头）。

## 三、怎么联机

1. 打开网址 → 「联机模式」
2. 一个人点「创建房间」，把 4 位房间号发给朋友
3. 朋友输入房间号点「加入」，或在「正在开放的房间」里直接点
4. 房主点「开始对局」。打完点「返回房间」，房主再开下一局时大家会自动进入

## 四、限制

- 联机局只有真人，没有 AI，建议 2–8 人；每个房间最多 16 人。
- 没有权威服务器：命中由开枪的一方判定，网络延迟时可能出现「躲进掩体后还是被打中」；有人改代码作弊无法完全阻止。
- 两人几乎同时捡同一件东西，可能两个人都拿到。
- 服务器限制：单条消息 8 KB、每个连接每秒约 40 条消息、同时在线 400 人；超过会被断开。
- 流量：实测两人对局时每人约 1 KB/s（一小时约 4 MB）；8 人局按比例估算约每小时 15–20 MB（估算值，未实测）。

## 五、更新游戏

替换 `public/index.html` 后重启服务器（`npm start`），或推送到 GitHub 让平台自动重新部署。
